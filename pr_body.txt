What changed:
Migrated `AgentFormModal.tsx` and `DepartmentFormModal.tsx` from custom div overlays to use `@radix-ui/react-dialog`. Both modals now benefit from robust keyboard accessibility (Escape key, Tab-trapping) and screen reader modality (`aria-hidden` outside the portal). Also updated `AgentFormModal.test.tsx` to handle Radix Portals by querying `container.ownerDocument` instead of `container`.

Why:
The dashboard modals previously used custom `div` overlays and manual `useEffect` hooks for Escape key handling, lacking comprehensive accessibility coverage (focus trapping, screen-reader modality). Migrating to Radix UI Dialog complies with existing AgentDesk accessibility standards, resolving concerns from previous overlapping PRs (#196 and #202).
