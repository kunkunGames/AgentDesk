What changed:
- Removed `Next Sprite` and `Previous Sprite` buttons from the tab order (`tabIndex={-1}`) in `AgentFormModal.tsx`.
- Updated `aria-valuetext` on the sprite `[role="spinbutton"]` from "선택된 스프라이트: X" / "Selected sprite: X" to "스프라이트 X" / "Sprite X" in `AgentFormModal.tsx`.
- Replaced the string literal "이모지" (Emoji) with "아이콘" (Icon) throughout `AgentFormModal.tsx` for consistency with `DepartmentFormModal.tsx`.

Why:
- Removing redundant buttons from the tab sequence adheres to the W3C ARIA Authoring Practices Guide for `spinbutton` widgets, as the main `spinbutton` element manages value changes via arrow keys.
- Simplifying `aria-valuetext` prevents screen readers from redundantly announcing "Selected" when the widget semantics implicitly convey the selection state.
- Harmonizing terminology ("Icon") across agent and department forms improves consistency for users and screen reader output.
